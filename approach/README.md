# Approach

Project approach, process set, framework, ontology, and viewpoints.

DE4SDV uses the ASELCM three-system framing to keep approach guidance scoped:

- **System 1** is the configurable SDV product line and configured
  vehicle/software variants.
- **System 2** is the DE4SDV life-cycle engineering and assurance system that
  manages System 1.
- **System 3** is the open innovation ecosystem that governs and evolves System 2.

This directory organizes reusable guidance for all three layers:

- [`framework/`](framework/) defines the conceptual framing.
- [`framework/ontology/`](framework/ontology/) defines reusable concepts and relationships.
- [`framework/viewpoint/`](framework/viewpoint/) defines stakeholder-specific views.
- [`process-set/`](process-set/) defines reusable process guidance.
