# Communication

DE4SDV uses GitHub as the source of truth for project work.

Use GitHub issues and pull requests for:

- contribution proposals
- technical questions that affect repository content
- bug reports, documentation gaps, and improvement requests
- decisions that need a durable public record

Mattermost is available for lightweight coordination at:

<https://chat.de4sdv.org>

Mattermost access is invite-only. This keeps the workspace useful and avoids
public-signup spam.

If you want an invite, open a GitHub issue using the **Mattermost invite
request** template and briefly include:

- who you are
- what you want to contribute or discuss
- why chat access would help

Do not use Mattermost as the only place for project decisions. If a decision
affects DE4SDV, capture it back in an issue, pull request, architecture
decision record, or repository document.
