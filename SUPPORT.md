# Support

For questions:

- Use [GitHub Discussions](https://github.com/de4sdv/DE4SDV/discussions) for
  questions, ideas, and community discussion. Discussions are enabled and are
  the fastest place to start.
- Use GitHub issues for bugs, documentation gaps, improvement proposals, and
  invite requests for the Mattermost workspace. The **Question or contribution
  proposal** template covers questions and proposals that should be tracked
  and triaged as issues.
- Use Mattermost for lightweight coordination after invite-only access is
  granted; see [`COMMUNICATION`](COMMUNICATION.md).
- For security vulnerabilities, follow [`SECURITY`](SECURITY.md).

Please include enough context to reproduce or understand the problem.
