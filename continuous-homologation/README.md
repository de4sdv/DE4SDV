# Continuous Homologation

Status: **incubating**. The directory defines evidence expectations but does
not yet provide an automated approval or release-evidence pipeline.

Continuous evidence preparation and compliance workflow. This is not a legal
approval claim.

## ASELCM scope

Continuous homologation is treated as a **System 2 capability** that prepares,
links, versions, and reviews evidence for **System 1** SDV product-line variants.

System 3 governs the methods, review expectations, standards mappings, and
project decisions that shape the continuous-homologation workflow.

## Evidence expectations

Evidence artifacts should identify:

- the System 1 feature, variant, behavior, hazard, threat, or compliance concern;
- the System 2 model, simulation, test, digital twin, baseline, or process that
  generated or manages the evidence;
- the System 3 decision, standard, or governance rule that shaped the evidence
  expectation;
- the evidence maturity, such as draft, example, reviewed, or validated; and
- any assumptions, limits, or unresolved expert-review needs.

No repository artifact should present draft evidence as certified, homologated, or
legally approved.
