# Maintainers

The project founder operates DE4SDV through the
[`@de4sdv`](https://github.com/de4sdv) GitHub account, which holds
administrator access to this repository.

| Name | GitHub | Role | Areas of responsibility | Authority |
|---|---|---|---|---|
| Orkun Yilmaz | [@de4sdv](https://github.com/de4sdv) | Project founder, lead maintainer, repository administrator | Project direction and roadmap; governance and contribution process; SysML v2 model architecture; product-line engineering; repository structure, CI, and deployment; compliance evidence structure | Final approval and merge decisions; role promotions; governance changes; administration of repository settings and branch protection |

Review and merge requirements, the role model, and the documented exception
path for administrator merges are defined in
[GOVERNANCE](GOVERNANCE.md).

Collaborator accounts with repository write access are managed in the
repository's GitHub settings. Write access alone does not confer reviewer or
maintainer status; roles are granted through the promotion path in
[GOVERNANCE](GOVERNANCE.md).
