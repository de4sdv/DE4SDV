# DevSecOps

Status: **active**.

This area records the repository's delivery and security-control posture. The
implemented workflows live under [`.github/workflows/`](../.github/workflows/);
[`devsecops-roadmap.md`](devsecops-roadmap.md) separates enabled controls from
open work so planned safeguards are not presented as operational.

Changes to security, permissions, credentials, or branch protection require
maintainer approval and must be verified against the live GitHub settings.
