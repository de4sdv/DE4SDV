# INC-AEBS-010 evidence

This directory contains runtime records and dispositions for the INC-AEBS-010
visualization campaign. Video bytes are intentionally not tracked. Their
checksums, former paths, retention status, and claim boundaries are recorded in
[`external-media.yaml`](external-media.yaml); the repository-wide rules are in
[`Evidence Management`](../../../../docs/evidence-management.md).

Small stills remain only where they support an identified state or preflight
observation. Repository presence does not upgrade a bounded observation into a
safety, compliance, or certification claim.
