# Contributing

Thank you for considering a contribution.

## Ways to contribute

- Improve documentation and terminology
- Add SysML v2 examples
- Add feature-model and variant-management examples
- Improve OSLC, digital thread, or digital twin guidance
- Add FMU/FMI/SSP simulation examples
- Improve safety/security/compliance evidence templates
- Triage issues and improve onboarding

## Before opening a pull request

1. Check whether an issue already exists.
2. Keep the change focused.
3. Update documentation and specs when behavior, assumptions, or structure change.
4. Run:

```bash
python scripts/check_repo.py
python scripts/smoke_test.py
```

## Review expectations

Reviewers check for:

- Clear user value
- Traceability to project goals
- Consistency with terminology
- No secrets or unsupported compliance claims
- Updated docs/specs/tests where relevant

## Contributor status

The project can later define contributor, maintainer, and steering roles in `GOVERNANCE.md`.
