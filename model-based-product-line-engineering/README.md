# Model-Based Product Line Engineering

Feature models, configurations, shared assets, and product models.

## ASELCM scope

Model-based product-line engineering is primarily **System 1-facing** content
managed by **System 2** processes.

- Feature models describe System 1 commonality and variability.
- Feature configurations select System 1 variants.
- Product models instantiate configured System 1 definitions.
- Shared assets are reusable System 1 engineering artifacts governed and baselined
  by System 2.
- Variant evidence links connect System 1 selections to System 2 verification,
  validation, simulation, digital-twin, safety, security, and compliance assets.

Product-line examples in this repository are reference assets and require
project-specific validation before operational or compliance use.
